# Projeto ONG — Juntos Fazemos a Diferença

Projeto front-end em HTML5 semântico desenvolvido para uma ONG fictícia.

## Estrutura
- `index.html`: apresentação institucional e contato.
- `projetos.html`: projetos, voluntariado e doações.
- `cadastro.html`: formulário com `fieldset`, `legend`, validações nativas e máscaras de CPF, telefone e CEP.
- `assets/css/style.css`: estilos responsivos.
- `assets/js/form.js`: máscaras e demonstração de validação no navegador.
- `assets/img/`: imagens JPG/WebP e elementos PNG/WebP.

## Observação
Os dados de contato e as imagens são genéricos e servem exclusivamente para demonstração.
